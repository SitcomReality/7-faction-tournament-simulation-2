# Phase 7: Visual & UX Polish

## Overview
Create distinctive art style with satisfying animations and clear visual communication.

## Stage 1: Color Scheme Design

### Step 1.1: Define Color Palette
- Unit colors (7 distinct, thematic)
- Player colors (7 distinct, separate from units)
- UI colors (background, panels, borders)
- Ensure accessibility (contrast, colorblind-friendly)

### Step 1.2: Apply Theme Consistently
- Update all UI components to use theme
- Ensure consistent spacing and sizing
- Create visual hierarchy
- Polish typography

### Step 1.3: Create Color Variants
- Hover states
- Selected states
- Disabled states
- Transition states

## Stage 2: Unit Symbols

### Step 2.1: Design SVG Symbols
- Create 7 unique SVG path symbols
- Ensure symbols are recognizable at small sizes
- Test symbols against different backgrounds
- Make symbols thematically coherent

### Step 2.2: Render Symbols on Grid
- Draw unit symbols in cells
- Scale symbols appropriately
- Layer symbols over territory colors
- Add subtle drop shadows or outlines

### Step 2.3: Symbol Animations
- Idle pulse or gentle movement
- Selection bounce or glow
- Spawn appearance animation
- Death/removal animation

## Stage 3: Territory Effects

### Step 3.1: Territory Transitions
- Animate ownership changes
- Border expansion animation
- Color transition effects
- Particle effects for capture

### Step 3.2: Territory Highlights
- Highlight selectable territories
- Show valid move targets
- Indicate contested areas
- Show adjacent territories to owned land

### Step 3.3: Border Rendering
- Draw clean borders between territories
- Thicken borders between different owners
- Add border glow or decoration
- Animate borders when territories change

## Stage 4: Action Feedback

### Step 4.1: Movement Animation
- Smooth unit movement between cells
- Arc or path animation
- Leave trail or footprints
- Arrival impact effect

### Step 4.2: Combat Effects
- Clash animation when units fight
- Victory/defeat indicators
- Damage numbers or symbols
- Screen shake or flash on big battles

### Step 4.3: Unlock Celebrations
- Flashy animation when unlocking unit
- Fanfare or special effect
- Brief description or lore
- Add to available units with flair

## Stage 5: UI Polish

### Step 5.1: Button States
- Clear hover feedback
- Satisfying click animations
- Disabled state clarity
- Loading/processing states

### Step 5.2: Panel Transitions
- Smooth panel open/close
- Slide or fade animations
- Maintain spatial awareness
- Minimize motion sickness

### Step 5.3: Tooltips & Hints
- Add helpful tooltips everywhere
- Show keyboard shortcuts
- Explain unit relationships on hover
- Tutorial hints for new players

## Stage 6: Audio (Optional)

### Step 6.1: Sound Effects
- Button clicks
- Unit placement
- Combat sounds
- Turn end chime

### Step 6.2: Music
- Ambient background music
- Different tracks for peace/war
- Victory/defeat music
- Mute/volume controls

## Notes
This phase focuses on making the game feel polished and professional. Every interaction should feel responsive and satisfying. Visual clarity is paramount - players should instantly understand game state.
